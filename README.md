# Razi Ashary — Portfolio

A responsive, static TypeScript portfolio built with Vite. Selected Work includes the three AI&You projects, Arcade, AutoDev (being refactored into Arcana) and a carefully limited AIRS Forge & Memory overview. Experience expands both roles from the supplied brief.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

The production site is written to `dist/`.

## Vercel

Connect the repository to Vercel. `vercel.json` sets `npm run build` as the build command and `dist` as the output directory. The project uses only static files and has no paid service or server dependency.

Public Google Drive demos are embedded in their matching case studies with a direct-link fallback; source MP4 files are excluded from the site bundle. The contact section includes a downloadable resume.
